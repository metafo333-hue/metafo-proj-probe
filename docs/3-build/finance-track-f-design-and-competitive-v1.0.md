### 1.2 战略空白（三路竞调收敛的核心判断）

1. **没有人做"跨域情报整合中台"**——问财管行情、天眼查管工商、IT桔子管一级，全是垂直深井。probe 横跨行情/宏观舆情/企业一级/理财四域整合，**国内外皆空白**。
2. **没有人把"抗污染验证"当卖点**——AlphaSense 把句子级引用做成工程，但没当对外卖点讲；国内通用 AI 金融输出无引用易幻觉。AI 幻觉+非法荐股泛滥下，"看见数据出处"是稀缺信任资产。
3. **传统巨头有创新者窘境**——不会推翻 $2.5万/年终端去做 $20/月 AI 助手。这个结构性空白只有 AI-native 新玩家能占，probe 无历史包袱可 AI-first。
4. **合规是护城河不是成本**——监管严打 AI 荐股窗口期，"只做信息不做建议"是持牌机构/媒体敢用的唯一选择。海外标杆因语言/区域/合规壁垒进不来中文金融。

### 1.3 差异化战略（四象限组合）

```
            合规公开源（不买断内容·27+官方源）
                      │
   中文平价 ──────────┼────────── AI-first 验证（句子级溯源）
   (¥3-30/件)         │
              多模态交付（文字/图/HTML/PPT/视频）
```

**护城河三柱**：① 看见数据出处（抗污染验证）② 合规（信息≠建议）③ 多模态成品（海内外都无人主打）。
**绝不正面**：Bloomberg 实时交易 · Wind 数据完整度 · 问财/妙想散户荐股红海 · Perplexity 通用消费级（靠垂直区隔）。

## 第二部分 · 设计方案

### 2.1 赛道定位

probe 金融 F = **跨域 AI 金融情报整合中台**（不做交易终端、不做投顾、不做垂直深井）。
- **做什么**：把分散的合规金融数据源，经 AI 检索-验证-整合，产出**可溯源的多模态情报成品**。
- **不做什么**：实时交易、荐股/投资建议、自建数据库、碰个人金融征信。
- **价值锚点**：从"帮你赚钱"（持牌雷区）转向"**帮你省调研时间 + 降低信息盲区 + 看见数据出处**"。

### 2.4 L1-L4 架构落点（复用 probe 四层）

| 层 | 职责 | 金融 F 落点 |
|----|------|------------|
| **L1 接入** | 数据源仓库+契约化热插拔 | 27+合规源注册成适配器（已有框架）·按 D11/D13/D14 域归类·gate19 核验门 |
| **L2 采集** | 标准化元数据 | 原料进结论出·只取公开元数据·守 API 配额限流即停（不换代理对抗）|
| **L3 验证** | 双审 8 闸抗污染（金融强化）| 见 2.5·**句子级溯源对标 AlphaSense 98%**|
| **L4 整合** | AI 跨源融合+多模态交付 | 跨 4 子域融合成稿·文字/图表/HTML/PPT/视频·接母体 wallet 管线 |

### 2.5 抗污染验证层（核心护城河）

金融是验证价值最高的赛道（AI 风险事件 2024 较十年前增 16 倍·2000+仿冒站编造收益）。

金融赛道验证 = 通用双审 8 闸（闸0-7·定义见 [probe-audit-system-v1.md](probe-audit-system-v1.md) §一，勿在此另立）。金融**专属加严**仅两条，作为既有闸的赛道规则扩展挂载，不新增闸编号：

- **越界拦截（投资建议/荐股）** → 挂闸6 对抗证伪 + 闸7 置信标注的金融子规则：输出含荐股/预测/"稳赚"字样 → 拦截 + 自动附免责声明（合规硬门）。
- **个保合规（PIPL）** → 由 `persist_policy` 留存门 + Guardian 处理（见 compliance-gates `verify_profile: finance-8gate` = 赛道准入门）：个人征信/流水字段 → 拒采拒落库，`persist_policy=sensitive`。

门/闸四套关系见 [records/probe-ssot-master-reconciliation-v1.0.md](../records/probe-ssot-master-reconciliation-v1.0.md) §3。

**对外卖点**："别的 AI 让你怀疑数据真假，probe 让你看见数据出处。"

### 2.6 与自媒体 A 域复用关系（战略交汇）

竞调三路收敛的 MVP=**财经自媒体创作者**，正是 **A 赛道（内容创作者）× F 赛道（金融数据）的交汇点**：
- 财经自媒体既是 A 域用户（要选题/数据/图表/合规检测），又消费 F 域数据（行情/舆情/公司）。
- 复用：A 域的内容场景框架 + F 域的金融数据底座 + 共用抗污染验证层 + 共用多模态交付。
- 这是 probe 两大主攻赛道**第一个该打通的交叉产品**。

## 第三部分 · 商业模式与落地

### 3.1 商业模式：按量 credits + 按件交付物（不走订阅）

| 决策 | 内容 |
|------|------|
| **底层计费** | 接母体声明式管线 `契约→dispatch→guard→wallet.debit`·注册 `tools/probe-finance/contract.py`·每次查询/报告按量扣费 |
| **交付层定价** | 单次成品定价 **¥3-30**（公司速读卡¥X/行业map¥Y/竞品PPT¥Z）·显著低于妙想818/季、企查查1800/年的"年费墙" |
| **免费钩子** | 每日 N 次免费试用（对标妙想3次/问财5次）·超额走 credits |
| **不走订阅** | 早期无月活基础·订阅"无限用"与"高质量验证"成本矛盾 |
| **锚点** | "用一次买一次"·正中母体"高效便宜有用·AI 结果交付系统"定位 |

### 3.3 MVP 切入点

**🥇 首推：财经自媒体 × 行情/宏观舆情子域 × 多模态数据卡/图表**
- 一句话生成"带验证来源的金融数据图表 + 公司/事件速读卡（HTML/图片）"，直接贴进公众号/小红书/视频。
- 五条理由：① 付费意愿最高变现最快 ② 完全避开合规红线 ③ 数据源已就绪（零成本） ④ 多模态是真差异化（现有财经写作工具无金融底座） ⑤ 抗污染验证直接变卖点（创作者怕引用假数据被打脸掉粉）。

**🥈 次推：中小企业 × 企业一级市场子域 × 竞品/行业速读报告**
