## 2. 批次划分原则

```
合规风险（免费合规 → 需资质 → 付费）  ← 主轴(永不代爬)
  × 旗舰 weight（F90 > G85 > H80，旗舰优先深耕）
  × 数据源就绪度（有官方API先 / 需逆向灰产弃）
  × 依赖（公共底座 → 横向域 → 旗舰专属 → 付费深探）
```

每个源的对接四门（不变）：**标准19 核验 → 合规门（§8.1 三 gate）→ R1/R4 授权（付费/资质）→ status=active 放行**。

## 6. 调研方法论（每批通用）

> 完整方法论（调研方向×内容×审核 + 开源/综合/权威三层选型优先级）见 **[datasource-research-methodology-v1.0](datasource-research-methodology-v1.0.md)**。要点：

0. **三层选型优先级**：每端口/域**先穷尽层1开源API**（零成本+主动权）→ 覆盖不足上层2综合服务 → 权威/深度缺口用层3权威官方补。
1. **扇出 N 路调研**（R36 并发）：每端口/每域并发 WebSearch + GitHub/官方文档查证，不靠单源印象（R0.8）。
2. **对抗证伪**：每个「有开放API/合规」结论派证伪路核验（默认 refuted，找到官方文档才采信）。
3. **标准19 接入门**：核验通过的源走既有 19 项核验落 ledger。
4. **能力价值目录**：每源产出 [source-selection](../3-build/probe-source-selection-and-capability-registry-v1.0.md) 的「能力×价值×成本×合规」条目，喂 Governor 选源查表。
5. **合规门前置**：B3/B4 的源先过 §8.1 对应 gate 再进调研，灰产源不浪费调研资源。

### 9.4 🔴 R4 公司资质门（须元东方授权·公司主体批量申请最优）

中国电商三大联盟（淘宝/京东/拼多多官方）+ 穿山甲 + 美团/抖音本地生活 + 值得买商业授权 —— 详分级见两份报告「待授权清单」节。建议公司主体（绵阳零元电子商务）成立/就绪后**一批统一申请**，避免重复手续。
