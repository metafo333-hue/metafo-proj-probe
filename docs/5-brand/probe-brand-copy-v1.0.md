### 2.4 How It Works（4步）

1. **输入查询** — 描述你想核查的人物、事件或议题
2. **意图确认** — 元探解析主体与意图，选择深度
3. **多源采集验证** — L1→L2→L3 八闸双审，实时展示进展
4. **结构化报告** — Admiralty 评级 + 七段报告，可导出分享
