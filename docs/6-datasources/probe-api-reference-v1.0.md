## 1. 事实核查与溯源 · D1 D4 D10

### Wikipedia / Wikimedia REST API

| 维度 | 内容 |
|------|------|
| **服务内容** | 词条摘要、全文摘录、分类树、页面 ID、多语言版本列表、关联页面 |
| **覆盖范围** | 57 个语言版本（中英日韩等）；6000 万+ 词条；实体/事件/概念/人物/地点 |
| **特点** | 无需 key；REST API 稳定；支持多语言切换；摘要接口极快（<200ms） |
| **特长** | 实体基础核查的**第一层**；快速判断某概念/人物/事件是否有百科入口 |
| **优势** | 权威度高（社区维护+编辑审核）；历史沿革可追；链接丰富可扩展 |
| **数据真实度** | ★★★★☆ — 社区众包，主流词条可信，冷门词条有失实风险，需交叉验证 |
| **速率限制** | 无官方限制，建议 ≤200 req/min；Wikimedia ToS 允许批量调用 |
| **接入状态** | live · 无需 key · `wikipedia.py` |

### GDELT Project

| 维度 | 内容 |
|------|------|

### SearXNG（自托管）

| 维度 | 内容 |
|------|------|
| **服务内容** | 聚合 Google/Bing/DuckDuckGo/Yandex 等 20+ 搜索引擎；返回标题、URL、摘要、来源引擎、发布时间 |
| **覆盖范围** | 任何关键词；支持 categories（general/images/news/videos/files）；支持语言/地区过滤 |
| **特点** | 自托管，无第三方 ToS 风险；JSON API 直接返回结构化结果；可指定特定引擎组合 |
| **特长** | probe 的**搜索入口层**：覆盖所有赛道，是没有专门 API 时的兜底检索手段 |
| **优势** | 不被任何单一引擎的反爬策略限制；聚合多引擎消除单一偏差；走 mihomo 代理绕过地区限制 |
| **数据真实度** | ★★★★☆ — 原始搜索引擎结果，真实性由各引擎保证；无自身加工失真 |
| **速率限制** | 无自身限制（取决于后端引擎配额）；ufo:8080 已部署 |
| **接入状态** | live · 需配置 `PROBE_SEARXNG_BASE` · `searxng.py` |

### SEC EDGAR（美国证监会）

| 维度 | 内容 |
|------|------|
| **服务内容** | 上市公司所有 SEC 申报文件（10-K 年报/10-Q 季报/8-K 重大事件/S-1 招股书）；CIK 编号查询；内部人持股（Form 4）；XBRL 结构化财务数据 |

| **特长** | **美股企业唯一一手财务源**：所有财务数据来自公司自报，法律级别真实 |
| **优势** | 完全免费；官方权威；不依赖任何第三方整理；追溯30年 |
| **数据真实度** | ★★★★★ — 公司法律义务申报，虚假申报构成证券欺诈，可信度极高 |
