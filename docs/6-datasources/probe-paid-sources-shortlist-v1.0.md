## 三、两条采购洞察（双螺旋 🛑 拍板前必认）

1. **B/C 共享工商源 → 一次采购两赛道共用**：天眼查/企查查同时服务 B（商业市场）+ C（尽调风控），**不重复采购**。但二者司法数据同源（聚合自同一批官网），互验只验「聚合准不准」、验不了事实本身 → 重大尽调结论须官网人工抽样兜底，标 `confidence=single-source-aggregated`。

2. **World-Check 非必需**：C 尽调国际合规层**首选自托管 OpenSanctions**（€1500/月级，490 万实体/376 数据集，已 curl verified）替代 World-Check（$11 万/年），**降本 80%+**。World-Check **降级为「跨境专项可选」**，仅高端跨境客户出现才触发（总方案 M3）。

3. **结构性合规债**：中国官方系统（gsxt/裁判文书网/NMPA 等）全部无 API + 铁律禁爬 → 四类付费硬缺口（工商司法/电商带货/比价CPS/中国药品）**只能走付费聚合商**，非省钱能绕开（总方案 §四）。
