## 三、拍板前必认的三个风险（双螺旋 🛑）

1. **结构性合规债**：中国官方系统（gsxt/裁判文书网/中国执行信息公开网/信用中国）**全部无官方 API**，probe 铁律禁爬 → 境内工商/司法/处罚**唯一合规路径就是付费聚合商**。这是结构问题，不是省钱能绕开的。
2. **同源伪冗余陷阱**：天眼查与企查查的**司法数据聚合自同一批官网**，两家互验只能查"聚合准不准"、**验不了事实本身**。重大尽调结论须官网人工抽样兜底，标 `confidence=single-source-aggregated`。
3. **采购前必核聚合商数据授权**：选定聚合商前须确认其数据来源**合法授权**，规避蝉妈妈式爬虫判例的连带风险。
