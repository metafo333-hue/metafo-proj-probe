## 〇、一句话

**对一个或多个「文案 / 材料 / 图片 / 视频链接 / 文档 / 名字实体」**，probe 经「多源采集 → 双审 8 闸 → 对抗证伪」产出**带可信度标签、可溯源、可证伪**的分析与报告。
下表按**判断意图**分**五组横向能力（T/D/A/B/C，任何行业通用）+ 一条垂直旗舰赛道（金融 F，复用横向+行业深耕）**；每类输出统一为「七段报告 + 三标签（可信度 / 来源强度 / 时效）」，按身份分公开评级 → 免费骨架 → 付费完整。

## 二、能力类别（五组 · 按判断意图）

### 组 T · 真实性 / 可信度类（probe 护城河核心）

| 代号 | 能力类别 | 一句话 | 典型输入 | 核心交付 | 状态 |
|------|---------|--------|---------|---------|------|
| T1 | **真实度审计** | 内容真伪 / AIGC 生成检测 / 数据核验 / 来源溯源 | 文案/图/视频/链接 | 真伪判定 + 证据链 + 三标签 | 8 闸核心·骨架✅·待接真模型 |
| T2 | **事实核查** | 逐条 claim 交叉证伪 | 文案/文档/链接 | 每条 claim 标真/疑/伪 + 出处 | 8 闸核心 |
| T3 | **版权 / 合规审计** | 二创可用性·BGM 版权·素材授权 | 视频/音频链接 | 能不能用 + 法律风险 | A5（27 场景内） |
| T4 | **风险扫描** | 合规·法律·资产·域名风险雷达 | 名字/域名/链接 | 风险雷达 + 等级 | C5（27 场景内） |

### 组 F · 金融投研类（垂直旗舰赛道 · 与 T/D/A/B/C 不同轴）

> **不同轴说明**：T-C 是**横向业务域**（按情报类型，任何行业通用）；**F 是纵向垂直旗舰赛道**（track-registry `tier=flagship`·weight=90·首个垂直样板），**复用横向能力 + 叠金融专属数据源/深耕/合规门**。能力定义不在此重写，真源见 [finance-track-f-design](3-build/finance-track-f-design-and-competitive-v1.0.md) + [track-registry](3-build/probe-track-registry-architecture-v1.0.md)。

| 代号 | 能力类别 | 典型输入 | 核心交付 | 复用横向 |
|------|---------|---------|---------|---------|
| F1 | 个股/公司**投研分析**（基本面+舆情+风险） | 公司名/标的 | 投研简报（**非荐股**） | B1 · T · C1 |
| F2 | **投融资尽调**（一级市场·值不值得投） | 公司名+文档 | 尽调报告（高价值付费·=D3） | C3 · D |
| F3 | 行业/赛道**研报** | 赛道关键词 | 金融视角全景 | B3 · D |
| F4 | 信用卡/理财产品**测评** | 产品名 | 测评（按"额度/征信/理财属性"走 F；"返现/折扣"属性归 G 元惠·边界见 track-registry） | B4 |

**金融合规红线（finance-gate-profile 赛道准入门 · 缺一即拦）**：
- **不荐股 · 不导流 · 不碰非持牌**；黑名单 = 场外配资 / 非法荐股 / 虚拟币传销盘（F 设计 §3.5 六红线）。
- **对外文案铁律**：只能叫「投研分析 / 尽调」，**禁出现"选股 / 推荐 / 带你赚"**字样。
- 当前 `incubating`，对外首发统一标 **Beta**。

## 二·补、能力面 ↔ 首页快选 ↔ 输出类型 映射桥（消三套分类漂移）

> **背景**：probe 现有三套"分类"——① 能力面五组+F（本册·按判断意图）② 首页快选按钮（UI 规格·用户语言）③ 六种输出类型（UI 规格·报告形态）。三者是**不同切面、非互替**；本桥定其对应关系，**任一处改动须回此表对账**（SSOT 防漂移）。
> **2026-06-15 决策（元东方）**：首页快选主轴 = **能力意图/领域轴**（= 本册五组+F 的用户语言投影），六种输出类型**降为次级形态选择**。UI 哲学「用户从不需要知道赛道」相应修订为「领域可选可隐·默认智能判断·内部'赛道'术语仍不外露」。

| 能力面（本册·内部口径） | 首页快选按钮（用户语言·主轴） | 默认输出类型（次级形态） |
|------------------------|-----------------------------|------------------------|
| 组 T 真实性/可信度 | 🔍 查真伪 · 辨 AI 生成 | 事实核查 |
| 组 A 内容/自媒体 | 🔥 拆爆款 · 竞品速读 | 竞调 / 咨询 |
| 组 C 背调/风控 | 🏢 背调一家公司 | 尽调 |
| 组 D 决策评估 | 📊 评估想法 / 方案 | 方案 |
| 组 B 商业/竞争情报 | 🛰 商业竞情 | 竞调 |
| 赛道 F 金融投研（垂直旗舰） | 💰 投研 · 尽调（金融 · Beta） | 尽调 / 研究报告 |
| —（任意领域深度版） | （二级 chip） | 研究报告 |
| —（不选 / 泛问） | 智能选取 ✦ | probe 自判 |

> **落点分工**：首页界面布局真源 = [UI 规格 §四 卡片 C1](5-brand/probe-ui-design-spec-v2.1.md)（只画界面、引用本桥定按钮↔能力）；本桥只定映射、不画界面（各司其责防重复）。

## 三、统一交付（所有类别共用）

| 维度 | 内容 |
|------|------|
| 报告结构 | 七段报告（design-v1 §5 真源） |
| 每条结论标签 | 可信度 + 来源强度 + 时效（三标签） |
| 三层深度线 | 匿名公开=评级+标题 · 免费登录=结构骨架 · 付费=完整 7 段 |
| 交付形态 | 文字 / 图 / HTML（M1）→ PPT / 视频（后期） |

## 四、边界（红线）

- **单条铁律「不自己爬」**：probe 不实施爬取/逆向/模拟登录；只用第三方合规 API（供应商担责）。
- 视频/social 提取须先经第三方合规 API；爬虫路径 `app/l0/_deprecated/` 已隔离。
- 人物背调（C2/T 类涉个人）守个保法最小必要 + 不落库双重硬保障。

---

## 五、新增类别纪律

- 标 🆕 的 **D1 立项评估 / D2 方案审核** 当前不在已落地 27 场景模板内，属**可新增类别**。
- probe 设计：**加场景 = 加模板（选哪几个信息域 + 哪种深度 + 哪种交付形态），不动引擎内核**（design-v1 §5）。
- 新增须走：补 ledger 信息域映射 → 加场景模板 → selftest 保持 11/11 → 入本册更新版本号。
