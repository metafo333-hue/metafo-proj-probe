## 0. 三条定位校准（贯穿全文 · 修订建议进 master-solution §0 / design-v1 §0）

| 旧表述（有问题） | 校准后 | 为什么 |
|---------------|--------|--------|
| "敢担保的结论" | **"每个数据/结论都有出处依据或逻辑依据，可溯源、可证伪"** | 担保=承担结果责任；probe 合规上"只信息不建议"，担不起。讲透明度而非保证，更诚实也更稳；一旦"担保"被识破，信任反噬比通用 AI 更狠 |
| A1 "30 秒判断能不能做" | **"30 秒把数据整理到位，做你身边的快速数据参谋，为你的决策备好依据支撑"** | 验证层能验事实/出处，**验不了"判断对错"**。probe 当数据参谋不当决策者，守在能力边界内，决策权还给用户 |
| 质量分档（免费轻验 / 付费全验） | **极速版 / 深度分析版双形态 · 智能界定（每版各自精品）**（2026-06-10 收敛 · 见 [speed-depth-tiering-v1.0](../3-build/probe-speed-depth-tiering-v1.0.md)） | 不是质量打折，是两种需求：极速版（快·留痕+溯源+交叉·标注未全验）在其定位也是认真精品、不糊弄；深度分析版（8闸全验+对抗证伪+多源专业数据）才是钱买的。系统智能界定走哪版（默认极速兜底+确定性自评+按需升级），既守精品底线又让资源匹配任务需要，解掉"人人8闸全开不可持续"的结构矛盾 |

## 1. 「评价/输出」到底有没有用（评价结论）

**校准后，probe 不再赌"判断准不准"（赌不赢），改赌"依据全不全、源真不真、链清不清"（这它能赢）。在此定位下对几乎所有人群都真有用，残余风险只剩两条且可从产品形态解。**

- **真有用**：用户痛点从不是"没有结论"（通用 AI 一秒给一堆），而是**"我不敢信、不知道它从哪来"**。probe 给"带出处的依据 + 反方 + 置信度"，把判断权连同弹药一起交给用户——通用大模型给不了。
- **残余风险 1（成本/延迟）** → §6 速览/深探双模 + 异步通知解。
- **残余风险 2（用户不看证据链）** → §4.1 分级呈现解（默认只给秒懂信号，要深究再下钻）。

两条都从形态上能解，不再是定位硬伤。

## 2. 五层价值模型（修订 · 建议进 design-v1 §0）

极速版 / 深度分析版双形态各自精品 = 五层在每版定位下都认真做到位；钱买的是**深度分析版**（8闸全验+对抗证伪+多源专业数据），不是"极速版打折"——另也含更多/更快/更多形态/更省事/更专属（见 §3）。系统智能界定走哪版（默认极速兜底+确定性自评+按需升级·见 [speed-depth-tiering-v1.0](../3-build/probe-speed-depth-tiering-v1.0.md)）。

| 层 | 价值 | 校准后定位 | 被替代难度 |
|----|------|-----------|-----------|
| L1 省时间·聚合 | N 源压成一次 | 基础 | 低（通用 AI 免费给） |
| L2 降盲区·覆盖 | 找到你不知道去哪找的源 | 基础+ | 中 |
| **L3 可信任·可溯源** | 出处依据/逻辑依据 + 多源交叉 + 反方 + 置信度 | **护城河核心** | 高 |
| **L4 可决策·依据支撑** | **做数据参谋：把决策要的数据/对比/出处整理到位，不替你下结论** | **临门一脚** | 高 |
| **L5 可交付·即用** | 按真实使用场景预设版式，拿来就能用 | **价值兑现的最后一公里** | 中高 |

横切：可复用（飞轮越用越准）、**可担责边界（信息≠建议、免责清晰 = 给用户安全感的价值，不是束缚）**。

> 关键判断：L1 单独不值钱；probe 的命门是 **L3+L4+L5 的组合**。现有方案两支柱（数据源+审核）只覆盖 L2/L3，**L4 依据整理质量、L5 交付翻译这两层被当成附属，实际它们才是用户"感知到有用"的临门一脚**。

## 3. 商业模式重构（对 master-solution §五 的修订建议）

> 真源是 master-solution §五（按量 credits + 按件交付物·不走订阅）。本节建议在其上**显式补入"质量解耦定价"原则 + 四条付费轴 + 用户×场景分层矩阵**。

### 3.1 原则：每版各自精品是地板，钱买深度分析版 + 四样东西

```
  ┌── 每版精品 = 极速版/深度分析版各自定位下都不糊弄；钱买的是深度分析版 ──┐
        │                                                            │
   ① 次数/配额      ② 输出形态        ③ 便捷性            ④ 特殊服务
   (免费N次/天      (文字→图→HTML      (异步多通道通知/     (人工复核背书/
    超额按量)        →PPT→视频，         优先队列/订阅监测/    定制模板/私有源/
                    高形态多花token)     批量/API/历史对比)    白标可商用/SLA)
```

**为什么这样强**：极速版也是认真精品（留痕+溯源+交叉，不糊弄）→ 免费用户第一口就吃到可信结果、口碑/转化天然；钱买的是**深度分析版**（8闸全验+对抗证伪+多源专业数据）+ 更多/更省事/更专属，付费理由清晰且用户心服（不是被卡质量，是要更深的验证与更省事/更专属）。系统智能界定走哪版让资源匹配任务需要，比"人人8闸全开"可持续。咬合母体"高效便宜**有用**"——人人有用，付费买深度与专属。

### 3.2 付费场景分层矩阵（用户档 × 场景）

| 用户档 | 心理 | 免费给什么 | 付费买什么（对应轴） |
|--------|------|-----------|---------------------|
| **C 端个人**（创作者/消费者） | 怕花钱、要即用 | 每日 N 次精品 + 文字/基础图 | 额外次数① · 升级视频/PPT 形态② · 多通道通知③ |
| **小 B**（MCN/卖家/独立开发） | 算 ROI、要效率 | 体验额度 | 月度配额包① · 批量③ · 订阅监测③ · API③ |
| **中大 B**（投资/品牌/法务） | 要专属、要背书、肯付高客单 | 样例报告 | **人工复核背书④ · 定制模板④ · 私有数据源接入④ · 白标可商用④ · SLA④** |

### 3.3 高端/特殊服务（④ 轴细化 · 高客单在这里）

- **人工专家二审背书**：AI 精品报告 + 行业专家复核签字（尽调/投资场景的信任溢价）
- **私有数据源接入**：把客户自有数据并入验证管线，产出私域情报
- **定制交付模板 + 白标**：客户品牌、可商用授权（咨询公司转售场景）
- **持续监测雷达（订阅制特例）**：B6 舆情 / C4 供应商风险——唯一适合订阅的形态（持续性=持续付费天然合理），与 master-solution §五"不走订阅"不冲突：一次性情报走 credits，持续监测走订阅，二者并存
- **SLA / 私密加密交付**：法务、投资的合规与时效保障

> 计费仍走母体声明式管线 `契约→dispatch→guard→wallet.debit`；**质量门（8 闸全开）对所有档位都跑**，扣费扣在"次数 × 形态 token × 特殊服务"，不扣在"验证强度"。

## 4. 行业价值主次 × 用户心理学 × 数据分级 × 场景聚合（建议进 design-v1 §5）

### 4.1 两条正交的「数据分级」轴

- **呈现深度轴（治认知负荷）**：`L0 秒懂信号(1 屏)` → `L1 关键依据(3-5 点带出处)` → `L2 完整明细(可展开)`。所有用户都能逐层下钻，差别只在"默认展开到第几层"。
- **置信度轴（治数据可靠性）**：每条数据/结论标 `高/中/低`，低置信醒目标"单源/存疑/待证"。这是 L3 可溯源在界面上的兑现。

不同人群 = 不同的"默认展开层 + 对置信度的敏感度"。

### 4.2 行业 × 心理画像 × 主次 × 分级 × 聚合（主表）

| 行业/人群 | 深层心理（想要 / 怕 / 决策风格 / 信任与分享） | C 位价值 | 默认呈现深度 | 场景聚合形态 |
|-----------|-------------------------------------------|---------|------------|------------|
| **自媒体创作者** | 想要爆款公式、不被甩开；**怕投入不爆(机会成本)、抄了违规、引错数据掉粉**；快决策+焦虑驱动；信"别人都在做"+具体数据，要**能直接发** | **L4 数据参谋 + L5 即用成品** | L0（信号+3 点） | 九宫格/竖屏视频脚本/可发文案 |
| **财经自媒体/金融** | 想要可信省时；**怕引假数据被打脸、踩荐股红线**；谨慎、责任意识强；信官方源+句子级出处+免责 | **L3 出处可溯 + 合规边界** | L1（每点挂源） | 带源链接的数据卡/图表+免责条 |
| **尽调/背调/风控** | 想要完整不漏可存档；**怕漏一个风险点担责、个保法违规**；宁全勿快、要审计痕迹；信覆盖度+证据链 | **L2 覆盖 + L3 证据链** | L2（全展开） | 风险清单（高/中/低排序）+证据档 |
| **调研/咨询/决策** | 想要站得住的判断、可引用；**怕被反例推翻、单源偏见**；重逻辑要反方；信引用规范+信源多样 | **L3 验证 + 反方观点** | L1→L2 | 论点-证据-反方-完整引用 |
| **核查（媒体/个人）** | 想要真假定论；**怕信了假的**；要干脆；信证据链 | **L3 验证 = 产品本身** | L0（三态） | 真/假/存疑 + 证据 + 置信度 |

**心理学要点（贯穿）**：
- 创作者**焦虑驱动** → 给确定性信号"降焦虑"，但**不替他拍板**（越俎代庖反而让他甩锅给你）；给"立刻能发"降执行成本。
- 金融/尽调**防御性决策（怕担责）** → 出处和免责不是合规负担，是**给用户"我尽职了/我有依据"的安全弹药**，本身是卖点。
- 所有人群：**降深度 ≠ 降质量**。精品内核照跑，只是默认折叠到用户认知带宽匹配的那一层，随时下钻。

### 4.3 同一内核 × 场景不同 → 聚合方式不同

验证后的内核只算一次，按场景重新聚合：速判→1 信号+3 点 / 对比→横评矩阵 / 监测→timeline+异动告警 / 尽调→风险清单+证据档 / 创作→可直接发布成品。

> **修订建议**：七段报告应是**可配置模板**，按行业把段落主次重排，不是一套打天下。建议在场景模板加"核心恐惧→C 位价值→段落主次"为第一字段。

## 5. 交付形态的实际场景设计（建议进 design-v1 §5.5）

铁律：**内核只算一次；形态是渲染层，但每种形态要"为真实使用场景预设好版式"，不是导出个通用文件。形态升级 = 多花 token（付费轴②），不多花数据成本。**

| 形态 | 真实场景 | 必须预设的细节 | 出处如何体现 |
|------|---------|--------------|------------|
| **图片** | 朋友圈/小红书/微博 | **朋友圈九宫格**：9 张 1:1(1080×1080)拼，每格承载一个点、首图抓眼、手机可读字号、留白；**小红书** 3:4 竖(1080×1440)+封面标题；**单图信息图** 一图看懂、配色无障碍 | 角落出处水印 / 二维码跳完整报告 |
| **视频** | 抖音/视频号/B 站 | 竖屏 9:16(短) vs 横屏 16:9；**前 3 秒钩子、字幕必加(静音观看)、结论前置、BGM 版权合规(A5)、封面** | 片尾出处卡 / 口播提及来源 |
| **文字/MD** | 公众号/小红书/即时对话 | 公众号(小标题+重点加粗+可扫读)、小红书(emoji+短段+话题标签)、对话场景(结论先行可直接转发) | 出处脚注 / 可点链接 |
| **HTML 交互** | 发 hub / 分享链接 | **H5-First（移动优先 · 平台铁律）**、可点击钻取(对应分级下钻)、数据表可排序、加载快、免费预览+付费全文权限 | 每个数据点可展开源 |
| **PPT** | 路演/汇报 | 投屏大字、每页一核心点、问题-数据-结论结构、专业模板、可导出 pptx 编辑、演讲者备注 | 页脚来源标注 |

> MetaAsk 在意图澄清时就确定形态+场景，避免"先出文字又返工做视频"。

## 6. 速度问题解法（建议进 design-v1 §4 / master-solution §三）

把"快速拍板"和"全验证"拆成两条路，不互相牺牲：

```
              ┌─ 速览模式：轻量即时(秒级) → 当场给 L0 信号(标注"速览·未全验")
一句话/链接 ──┤
              └─ 深探模式：全 8 闸 + 对抗证伪(异步) → 用户切走干别的
                         └─ 完成 → 多通道通知(微信/Push/邮件/站内，用户挑)
```

- 多通道通知既解延迟，又是**付费便捷轴③**（优先队列=插队更快、多通道=想怎么收怎么收）。
- 落地有现成底座：`origin-notify.py`（Server酱微信推送）可接 probe 异步完成回调。
- **铁律**：⚡极速版必须显著标"未全验·重大决策请用深度分析版"，否则用户拿轻验结果当尽调 → 违背"每版各自精品·可溯源"承诺。极速版是"先看个方向"的认真快品，🔬深度分析版才是可溯源可证伪的全验交付物（对应 [speed-depth-tiering-v1.0](../3-build/probe-speed-depth-tiering-v1.0.md) 透明铁律）。

## 7. 五条还没碰的硬骨头（落地前必补 · 按风险排序）

> ①② 会出事（烧钱/违法），建议进 [Wave 1](../probe-master-solution-v2.md)；③④⑤ 限天花板，随场景落地补。

### ① 钱：双形态智能界定的单位经济学（最高风险）
若"人人 8 闸全开 + opus×5 + 付费源调用" = 每份成本不低，免费 N 次/天必烧穿——这正是改双形态智能界定（默认极速兜底+确定性自评+按需升级·见 [speed-depth-tiering-v1.0](../3-build/probe-speed-depth-tiering-v1.0.md)）的根因：极速版（闸0/1/2/7[+3/5]）成本低且仍精品，深度分析版（8闸全验+对抗证伪）按需触发由钱覆盖。补：
- **每份报告设成本上限**（token+源调用封顶，超了降形态不降验证）
- **验证内核缓存复用**：同一链接/实体已分析过 → 复用已验证内核，只重渲染形态，不重跑 8 闸（调和"每版各自精品"与"成本可控"的关键机制）
- **免费额度按 LTV>CAC 反推**，不拍脑袋

### ② 法：「第三方担责，probe 只调用」是幻觉（严重 · 现有方案过度乐观）
三处供应商担不了的责（合规真源仍是 [feasibility-v1 §5](../4-research/probe-github-datasource-feasibility-v1.md)，本条为补充其未覆盖面）：
- **数据出境**：probe 调海外 API 传中国用户数据，**probe 自己就是出境方**，供应商不挡
- **二次分发/白标④**：转售第三方数据可能违反该 API 的 ToS，"再分发"是 probe 的责任
- **个保法**：就算每个源合规，probe 把碎片**拼成一份人物背调**这个"处理"动作本身可能违法

补：probe 必须有**自己的合规判定层**（出境拦截/再分发授权核验/敏感拼装阻断），不能全外包给"调用方无责"假设。

### ③ 链路命门：MetaAsk 意图澄清是单点死穴（最高杠杆 · 最少讨论）
整条链 `意图→形态→深度→交付` 全挂在 MetaAsk 准不准。意图抓错 = **精准地回答错问题**，精品报告反而更危险（用户更信）。"所问即所得"的前提是"所问被听懂"。补：高客单/不可逆形态（PPT 路演、尽调背书、白标交付）交付前必须**意图复述确认**（对应 R-CL）；速览可跳过。

### ④ 信任闭环：「可证伪」的另一面没设计
换掉"担保"=公开承认"用户会找到错"，但没设计找到错之后怎么办：
- **错误修复闭环**：报告内置"这条我存疑/数据像旧的"反馈入口 → 进飞轮（错误是最值钱的训练信号，不是事故）
- **报告保鲜期**：精品报告是快照，金融/舆情几天就馊。九宫格发了朋友圈下周可能就错。必须**标时效 + 过期提醒**，而这恰是**"一次性情报 → 订阅监测雷达"的天然升级桥**（过期→提示订阅持续盯），把信任和变现一起接上

### ⑤ 战略诚实：护城河会被抄 + 冷启动鸡生蛋
- **单轴护城河都薄**：Perplexity/通联萝卜半年内都能加"引用出处"。护不动的是**累积**——catalog 广度 × 各源对各类问题命中率数据 × 按行业心理调好的场景模板，**抄不走的是数据飞轮不是功能**。别信"验证层=护城河"的单点叙事
- **冷启动鸡生蛋**："越用越准"要用量数据，上线时没有。得先**喂一套源-场景匹配的先验**（用调研/专家经验播种），否则第一批用户拿到的精品撑不起口碑，飞轮转不起来
